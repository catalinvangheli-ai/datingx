Politica de Confidentialitate - DatingX

Ultima actualizare: 23 martie 2026

1. Cine suntem

DatingX este o aplicatie de dating orientata pe compatibilitate. Aceasta politica explica ce date colectam, de ce le colectam si cum le protejam.

Contact: contactdatingx@gmail.com

2. Ce date colectam

  1. Date de cont: adresa de email, parola (stocata doar hash).
  2. Date de profil: nume, varsta, gen, locatie, preferinte si criterii completate de utilizator.
  3. Continut utilizator: fotografii, mesaje, anunturi publicate.
  4. Date tehnice minime: token-uri de autentificare si loguri operationale.

3. Cum folosim datele

  • Creare si administrare cont
  • Autentificare si securitate
  • Functionarea functiilor principale: profil, anunturi, chat, cautare
  • Prevenirea abuzului si mentenanta serviciului

4. Partajarea datelor

Nu vindem date personale. Datele pot fi procesate de furnizori tehnici necesari functionarii aplicatiei (hosting, baza de date, stocare imagini).

5. Durata stocarii

Datele sunt pastrate cat timp contul este activ sau cat este necesar pentru obligatii legale si securitate.

6. Securitate

Folosim masuri rezonabile de securitate, inclusiv conexiuni HTTPS, control acces si parole hash.

7. Drepturile tale

Poti solicita acces, corectare, stergere sau restrictionare, conform legii aplicabile.

8. Contact

Pentru orice solicitare privind datele personale: contactdatingx@gmail.com

Aceasta politica poate fi actualizata periodic. Versiunea afisata este versiunea curenta.
